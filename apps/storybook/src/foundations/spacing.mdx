# Spacing

Thang spacing dùng cho `padding`, `gap`, `margin`. Đơn vị cơ sở là `0.25rem` (4px).

<SpacingScale />

## Rule

- Spacing trong component lấy từ CSS variable `--ds-spacing-*` hoặc Tailwind preset.
- Không dùng magic number cho padding/gap/margin.
